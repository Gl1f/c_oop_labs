# Лабораторные по ООП

Учебный проект на C++: консольная «Матрица» со случайными символами. Первая лабораторная рисует одну линию заданной длины и скорости. Вторая добавляет частоту появления и несколько одновременных линий без потоков.

Технологии: C++11, WinAPI, MinGW-w64 или Visual Studio. CMake используется как дополнительный способ сборки.

## Ветки

- `about`: общее описание проекта, только этот README.
- `develop`: разработка всех лабораторных по порядку. Сейчас реализована лабораторная №2.
- `lab-01`: стабильная версия лабораторной №1 после проверки преподавателем. Пока ветка не создана.
- `lab-02`: стабильная версия второй лабораторной после проверки преподавателем. Пока ветка не создана.
- `lab-03`–`lab-04`: будущие работы, пока не реализованы.

## Первая лабораторная

Номер 11, первая половина группы. Движение слева направо, форма — ромб. В режиме `N` символы зелёные, в режиме `Y` каждый символ получает случайный цвет. Используются классы `Symbol`, `Line`, `Application`, `Console`.

## Сборка и запуск

Переключиться на ветку `develop`. Нужны Windows и компилятор C++.

Для MinGW-w64 добавить его папку `bin` в `PATH`:

```bat
git switch develop
build.bat
build\matrix.exe 3 23 8 Y
```

Или собрать с CMake в терминале с настроенным MinGW-w64 либо Visual Studio C++:

```bat
cmake -S . -B build
cmake --build build --config Release
```

Результат для MinGW: `build\matrix.exe`; для Visual Studio: `build\Release\matrix.exe`.

Теперь порядок параметров: частота появления 1–30, скорость 1–30, длина 1–30 и флаг `Y/N`. Без аргументов начинается диалоговый ввод. Справка: `matrix.exe --help` или `matrix.exe /?`. Выход из анимации: **Esc**.

Вторая лабораторная выбирает случайные моменты появления линий в каждой секунде. Каждая линия управляет своей скоростью; менеджер координирует их без потоков. Подробнее — в README ветки `develop`. Первая работа сохранена в истории, коммит `dc4f127`.
