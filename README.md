# Лабораторные по ООП

Учебный проект на C++: консольная «Матрица» со случайными символами. Первая лабораторная рисует одну линию заданной длины и скорости. Вторая добавляет частоту появления и несколько одновременных линий без потоков. Третья добавляет взрывы и уменьшение длины линий.

Технологии: C++11, WinAPI, MinGW-w64 или Visual Studio. CMake используется как дополнительный способ сборки.

## Первая лабораторная

Номер 11, первая половина группы. Движение слева направо, форма — ромб. В режиме `N` символы зелёные, в режиме `Y` каждый символ получает случайный цвет. Используются классы `Symbol`, `Line`, `Application`, `Console`.

## Сборка и запуск

Переключиться на ветку `develop`. Нужны Windows и компилятор C++.

Для MinGW-w64 добавить его папку `bin` в `PATH`:

```bat
git switch develop
build.bat
build\matrix.exe 3 23 8 Y 50 2 5
```

Или собрать с CMake в терминале с настроенным MinGW-w64 либо Visual Studio C++:

```bat
cmake -S . -B build
cmake --build build --config Release
```

Результат для MinGW: `build\matrix.exe`; для Visual Studio: `build\Release\matrix.exe`.

Порядок параметров: частота появления 1–30, скорость 1–30, длина 1–30, флаг `Y/N`, вероятность взрыва 1–1000, минимальный и максимальный радиус 1–10. Максимальный радиус не меньше минимального. Без аргументов начинается диалоговый ввод. Справка: `matrix.exe --help` или `matrix.exe /?`. Выход из анимации: **Esc**.

Вторая лабораторная выбирает случайные моменты появления линий в каждой секунде. Каждая линия управляет своей скоростью; менеджер координирует их без потоков. Подробнее — в README ветки `develop`. Первая работа сохранена в истории, коммит `dc4f127`.

## Третья лабораторная

Добавлен абстрактный класс `Figure`, от которого наследуются `Line` и `Explosion`. На каждом шаге линия может взорваться с вероятностью, заданной числом шансов из 1000, и стать короче на один символ. Взрывы расходятся со скоростью 2 клетки радиуса в секунду и всегда получают случайные цвета. Память управляется контейнерами C++ и `unique_ptr`.

Вторая работа сохранена в истории, коммит `3fc5e64`.
