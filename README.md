# Матрица

Лабораторная работа №1 по ООП на C++. Программа рисует в консоли линию из случайных печатных символов. Когда линия полностью выходит за правую границу, появляется следующая на случайной высоте.

Номер в списке: **11**, первая половина группы:

- `11 % 4 = 3`: слева направо;
- `11 % 3 = 2`: ромб;
- режим `Y`: случайный цвет для каждого нового символа;
- режим `N`: зелёный цвет.

Используются C++11 и WinAPI. Сборка через MinGW-w64 или CMake.

## Ветки

- `develop`: код и описание текущей лабораторной. Следующие работы продолжаются здесь.
- `about`: только общий README проекта.
- `lab-01`: ветка для проверенной версии первой лабораторной, создаётся после проверки преподавателем.

Лабораторные 2–4 пока не реализованы.

## Сборка и запуск

Нужна Windows и компилятор C++: MinGW-w64 (например, w64devkit) либо Visual Studio с компонентом разработки на C++.

Самый короткий путь для MinGW: добавить папку `bin` компилятора в `PATH` и запустить `build.bat`. Программа появится в `build\matrix.exe`.

То же самое вручную из папки проекта:

```bat
g++ -std=c++11 -Wall -Wextra -pedantic src\main.cpp src\Application.cpp src\Console.cpp src\Line.cpp src\Symbol.cpp -o matrix.exe -luser32 -static
matrix.exe 23 8 Y
```

Либо через CMake в терминале с настроенным компилятором:

```bat
cmake -S . -B build
cmake --build build --config Release
```

Для MinGW результат — `build\matrix.exe`, для Visual Studio — `build\Release\matrix.exe`.

```bat
build\matrix.exe
build\matrix.exe 23 8 Y
build\matrix.exe 10 15 N
build\matrix.exe --help
build\matrix.exe /?
```

Без аргументов программа последовательно спрашивает скорость (1–30), длину (1–30) и режим (`Y/N`). Неверное значение нужно ввести заново. В CLI неверные параметры завершают программу с сообщением об ошибке. Для выхода из анимации нажать **Esc** в активном окне консоли. Английские сообщения в консоли позволяют не настраивать кодировку.

## Как устроено

- `Symbol` хранит символ, координаты и цвет, умеет появляться и стираться.
- `Line` создаёт символы ромба и стирает хвост. Массив выделяется через `new[]` и освобождается через `delete[]`. Копирование линии запрещено, чтобы не освобождать один массив дважды.
- `Application` проверяет параметры и запускает линии по очереди.
- `Console` работает с WinAPI, размером окна, цветом, клавишей Esc и задержками.

Форма повторяется по образцу из ТЗ, повёрнутому для движения вправо:

```text
 B E H
A D G J
 C F I
```

Буквы здесь показывают порядок появления, а в программе вместо них случайные символы. За шаг появляется один символ. Длина считается в символах, поэтому у головы и хвоста ромб может быть неполным. При входе и выходе часть линии находится за границей экрана. Символы в середине линии сохраняют координаты и цвет.

Размер окна берётся перед началом анимации. Если размер нужно изменить, остановить программу и запустить заново. Для ромба нужно окно высотой хотя бы 3 строки.

## Проверка вручную

1. Открыть `--help` и `/?`.
2. Проверить скорость и длину 1 и 30.
3. Ввести `0`, `31`, `abc`, `2.5`, неверный флаг и лишние аргументы: программа должна отклонить ввод.
4. Запустить с `N`, затем с `Y`: зелёные символы или отдельный цвет каждого символа.
5. Дождаться ухода линии и появления новой. Проверить выход по Esc.

После проверки преподавателем сохранить стабильную версию:

```bat
git switch develop
git switch -c lab-01
git push -u origin lab-01
```
