# Матрица — лабораторная №4 «Велосипедизация»

Четвёртая работа продолжает ЛР №2. Несколько линий движутся одновременно, а расписание и движение обрабатываются в одном цикле. Вариант 11, первая половина группы. Ромбы движутся слева направо. В режиме `N` линии зелёные, в режиме `Y` каждый новый символ получает случайный цвет.

## Запуск

```bat
build\matrix.exe 3 23 8 Y
build\matrix.exe
build\matrix.exe --help
```

Аргументы по порядку: частота появления, скорость, длина, `Y/N`. Первые три параметра принимают целые числа от 1 до 30. Частота измеряется в линиях в секунду, скорость — в символах в секунду. Без аргументов параметры вводятся последовательно с повтором при ошибке. Справка также доступна через `/?`. Выход из анимации по Esc.

## Свои контейнеры

- `List<T>` — абстрактный интерфейс. Задаёт добавление в конец, вставку по позиции, удаление по позиции, получение размера и доступ по индексу.
- `LinkedList<T>` — односвязный список. Каждый узел хранит значение и указатель на следующий узел. Начало и конец списка хранятся отдельно. Используется для символов в `Line` и активных линий в `Application`.
- `ArrayList<T>` — динамический массив. При заполнении выделяет массив большего размера, переносит элементы и освобождает старый. Используется для миллисекундных времён запуска линий и буфера кадра. Для этой реализации тип элемента должен поддерживать создание по умолчанию и присваивание.

Индексация начинается с нуля. Вставить элемент можно в том числе на позицию `size()`, а обратиться к элементу или удалить его — только по индексу меньше `size()`. Ошибочный индекс вызывает `std::out_of_range`. Оба контейнера освобождают свою память автоматически при уничтожении. `unique_ptr` отвечает за владение массивом и объектами линий.

## Как работает анимация

В начале секунды менеджер выбирает случайные моменты запуска в пределах 0–1000 мс от её начала. Итоговые миллисекундные времена хранятся в `ArrayList` и сортируются. Когда время запуска наступает, новая линия добавляется в `LinkedList`. Каждая линия делает шаги по своей скорости. При заполнении линии удаляется символ хвоста и добавляется новая голова. После правой границы остаётся постепенное стирание хвоста.

Общий кадр собирается из всех активных линий. Благодаря этому символ из одной линии не пропадает при уходе другой линии из той же клетки. Размер окна определяется при запуске, для ромба нужны как минимум три строки.

## Сборка

Нужна Windows и MinGW-w64 или Visual Studio с поддержкой C++. Для MinGW добавь его папку `bin` в `PATH` и запусти `build.bat`. В терминале с настроенным компилятором также можно использовать CMake:

```bat
cmake -S . -B build
cmake --build build --config Release
```

MinGW создаёт `build\matrix.exe`, Visual Studio — `build\Release\matrix.exe`.
