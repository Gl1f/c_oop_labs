# Матрица — лабораторная №3 «Взрыв»

Продолжение второй работы по ООП на C++11 и WinAPI. Одновременно движутся несколько линий, которые могут взрываться и постепенно укорачиваться.

Вариант сохранён: номер **11**, первая половина группы. Ромбы движутся слева направо. Режим `N` делает линии зелёными, `Y` задаёт случайный цвет каждому новому символу.

## Запуск

Готовая программа — `build\matrix.exe`:

```bat
build\matrix.exe 3 23 8 N 50 2 5
build\matrix.exe 1 5 15 Y 1000 3 3
build\matrix.exe
build\matrix.exe --help
build\matrix.exe /?
```

Порядок семи параметров:

| Параметр | Допустимые значения |
| --- | --- |
| Частота появления | 1–30 линий в секунду |
| Скорость линии | 1–30 символов в секунду |
| Начальная длина линии | 1–30 символов |
| Режим цвета линии | Y/N, также y/n |
| Вероятность взрыва | 1–1000 шансов из 1000 на шаг |
| Минимальный радиус | 1–10 клеток |
| Максимальный радиус | 1–10, не меньше минимального |

Без аргументов параметры запрашиваются по очереди. При ошибке повторяется ввод текущего значения. В CLI неправильные параметры завершают программу с сообщением. Выход из анимации — Esc.

## Взрывы

На каждом шаге, пока у линии есть видимые символы, выполняется `rand() % 1000 < probability`. Здесь 1 означает 0,1%, 50 — 5%, 1000 — 100%. Проверка идёт на шаг линии, а не один раз в секунду: быстрая линия получает больше проверок за секунду.

Центр взрыва — голова линии, то есть первый символ по направлению движения, после выполнения очередного шага. Для каждого взрыва случайно выбирается предельный радиус между минимальным и максимальным включительно. При равных границах радиус фиксирован.

Использована простая форма из первого рисунка ТЗ: контур ромба. В момент рождения появляется радиус 1, через 500 мс — 2, через 1000 мс — 3 и так далее до выбранного предела. Последняя стадия тоже видна 500 мс, затем взрыв исчезает. Это 2 клетки радиуса в секунду независимо от скорости линии.

На каждой стадии создаются случайные печатные символы со случайными цветами, даже если линия зелёная. Вылезающая за окно часть взрыва обрезается. Центр остаётся в месте взрыва и не движется вместе с линией.

Каждый взрыв уменьшает допустимую длину исходной линии на единицу. При необходимости удаляется лишний символ хвоста, остальные продолжают движение. При длине 0 линия удаляется. Её уже появившиеся взрывы продолжают существовать самостоятельно. Новые линии продолжают появляться с заданной частотой.

## Классы и память

- `Figure` — абстрактная фигура с чисто виртуальными `draw` и `isFinished`, а также виртуальным деструктором.
- `Line : public Figure` — движение ромба, собственная скорость, проверка взрыва и уменьшение длины.
- `Explosion : public Figure` — центр, случайный предельный радиус и стадии по 500 мс.
- `Symbol` — координаты, знак и цвет.
- `Application` — ввод, расписание появления, обновление линий и взрывов. Метод `drawFigure(const Figure&, ...)` вызывает нужную отрисовку через базовый класс.
- `Console` — системные функции, ввод, кадр и Esc.

Линии хранятся в `vector<unique_ptr<Line>>`, взрывы и символы — в `vector`. Память освобождается автоматически при удалении объектов. Символы линии теперь хранятся от хвоста к голове; это упрощает уменьшение её длины. Удаление первого элемента вектора не меняет экранные координаты остальных символов.

Вся работа выполняется в одном цикле, без дополнительных потоков. Появления линий планируются на случайные моменты 0–1000 мс каждой секунды, как во второй работе. Совпадающие моменты допустимы. Если кадр задержался, учитываются просроченные шаги и времена рождения взрывов.

При изменении состояния собирается общий кадр. Сначала рисуются линии, поверх — взрывы. При пересечении видна последняя нарисованная фигура; после её ухода оставшиеся восстанавливаются. Размер окна запоминается при запуске: после изменения размера программу нужно перезапустить. Скорость вывода зависит от нагрузки Windows.

## Сборка

Нужна Windows и MinGW-w64 либо Visual Studio с C++. Для MinGW добавить папку `bin` компилятора в PATH и выполнить `build.bat`.

Вручную:

```bat
g++ -std=c++11 -Wall -Wextra -pedantic src\main.cpp src\Application.cpp src\Console.cpp src\Line.cpp src\Symbol.cpp src\Explosion.cpp -o matrix.exe -luser32 -static
```

Через CMake в терминале с настроенным компилятором:

```bat
cmake -S . -B build
cmake --build build --config Release
```

MinGW создаёт `build\matrix.exe`, Visual Studio — `build\Release\matrix.exe`.

## Проверка вручную

1. Открыть справку и запустить программу без аргументов.
2. Проверить неверные числа, флаг и максимальный радиус меньше минимального.
3. Запустить `1 5 15 N 1000 3 3`: зелёная линия уменьшается на каждом шаге, цветные взрывы доходят до радиуса 3.
4. Сравнить скорость линий 1 и 30: стадии взрывов в обоих случаях сменяются каждые 500 мс.
5. Проверить вероятность 1 и 1000, длину 1 и 30, радиусы 1 и 10.
6. Дождаться полного уничтожения линии и исчезновения её взрывов. Завершить по Esc.
