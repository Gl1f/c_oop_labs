# Лабораторные по ООП

Учебный проект на C++11 и WinAPI. Программа рисует в консоли линии из случайных символов. Сборка через MinGW-w64 или Visual Studio, также есть описание сборки для CMake.

Вариант 11, первая половина группы. Линии в форме ромба движутся слева направо. В режиме `N` символы зелёные, в режиме `Y` каждый новый символ получает случайный цвет.

## Работы и ветки

| Работа | Что реализовано | Версия в истории |
| --- | --- | --- |
| №1 | Одна линия, скорость, длина и цвет | `dc4f127` |
| №2 | Частота появления и несколько линий в одном цикле | `3fc5e64` |
| №3 | Абстрактная фигура, наследование и взрывы | `bb85afd` |
| №4 | Поведение второй работы со своими шаблонными контейнерами | `develop` |

В `about` находится только это описание. В `develop` ведётся работа над проектом. Стабильные ветки `lab-01`–`lab-04` создаются после проверки преподавателем.

## Запуск четвёртой лабораторной

В Windows переключиться на `develop`. Для MinGW-w64 добавить папку `bin` компилятора в `PATH`:

```bat
git switch develop
build.bat
build\matrix.exe 3 23 8 Y
```

Альтернативная сборка через CMake в терминале с настроенным компилятором:

```bat
cmake -S . -B build
cmake --build build --config Release
```

MinGW создаёт `build\matrix.exe`, Visual Studio — `build\Release\matrix.exe`.

Порядок параметров: частота появления, скорость, длина, `Y/N`. Первые три значения от 1 до 30. Без аргументов программа спрашивает параметры по очереди. Справка через `--help` или `/?`, выход из анимации по Esc.
